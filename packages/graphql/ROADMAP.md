# graphql roadmap

`graphql` builds schemas from runtime type values and executes queries. See [README.md](README.md) for usage.

## Next work

- Expand specification coverage with focused compatibility tests.
- Improve validation and execution diagnostics.
- Add batching or schema tools when application use shows a clear need.

Build a schema with the type builders, or read one from SDL with `Schema.from_sdl`.
