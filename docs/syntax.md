# Language reference

Diamond's language and standard-library reference is organized by topic:

- [Core syntax and values](core-syntax.md) — expressions, control flow,
  assignment, numbers, ranges, and symbols.
- [Functions, closures, and calls](callables.md) — blocks, keyword and
  variadic arguments, and call-site spread.
- [Classes, modules, and methods](classes-and-modules.md) — inheritance,
  singleton methods, visibility, operators, and method references.
- [Gradual typing and exceptions](types-and-errors.md).
- [Collections and Enumerable](collections.md).
- [Runtime features and debugging](runtime-reference.md) — Fibers, I/O entry
  points, bytecode diagnostics, regular expressions, and compiler overview.

Related guides cover [Time](time.md), [Fibers](fibers.md),
[Threads](threads.md), and [I/O and native services](io.md) in more depth.
