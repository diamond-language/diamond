Get started

Start with a cut

Install Diamond and facet using the build instructions, then in a new project:

my_app 
facet init my_app
facet add logger --registry https://cuts.dilang.tech --version '^0.4.0'
facet update

Commit diamond.cut and facet.lock. On another machine, facet install reproduces the locked versions and verified archives. Use facet update when you intend to resolve newer versions.

Yanked releases stay available to existing locks but are excluded from new resolution. A taken-down release is unavailable.

Publishing

Publish your own cut

Publishing is limited to operator-approved maintainers with scoped credentials. Request maintainership, then check your cut:

my_cut 
facet check path/to/my_cut
facet pack path/to/my_cut my_cut.tar
facet verify my_cut.tar

Declare public maintainers in diamond.cut; the catalog shows them. Versions are immutable: publish changed contents under a new cut version.

See the cut contract for dependency, archive, and publishing requirements.
